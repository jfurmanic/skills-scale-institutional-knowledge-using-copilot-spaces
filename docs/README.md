# OctoAcme Project Management Docs

## Overview
This folder is the central hub for OctoAcme's project management documentation. Our approach is customer-first, iterative, and grounded in clear ownership, data-informed decisions, and psychological safety so teams can deliver value, learn quickly, and improve together.

At a high level, the project lifecycle moves from initiation and planning into execution, release, and retrospective. Teams start by defining the problem, success metrics, stakeholders, and risks, then break work into manageable increments, track delivery, communicate clearly, and validate quality before release. For the complete lifecycle, guiding principles, roles, and core artifacts, start with the [Project Management Overview](./octoacme-project-management-overview.md).
